# Security policy

Please do not report vulnerabilities, credentials, private documents or database files in public issues.

## Reporting

This preview repository does not currently publish a dedicated security contact address. Until an official private reporting channel is added, do not disclose sensitive details publicly. Contact the project owner through the authenticated GitHub account or repository administration channel and request a private reporting route.

Include a short description, affected component, reproduction steps that do not contain personal data, and the potential impact. Redact tokens, API keys, private documents and local database contents.

## Scope

Reports about local document exposure, unintended network activity, IPC authorization, credential handling and packaging leaks are especially important. AI is disabled by default in V1, and dictionary data has separate licensing and packaging requirements.
